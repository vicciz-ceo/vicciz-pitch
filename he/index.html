סוכן ה-AI לתיאום המשך הטיול כשהטיסה משתבשת

עיכוב בטיסה יכול לשנות גם את הצ׳ק-אין במלון, את איסוף ההסעה ואת שעת הפעילות. Kiipling מרכז את ההזמנות שנפגעו ומכין את הפניות לספקים שצריכים לתאם איתם את השינוי.

vicciz היא חברת טכנולוגיה בתחום התיירות שמפתחת את Kiipling — סוכן AI לתיאום הטיול אחרי ההזמנה. כשיש שיבוש בטיסה, הסוכן מזהה הזמנות שעלולות להיפגע, מכין פניות לספקי המלון, ההסעה והפעילויות, ועוקב אחר התשובות באותו אירוע. הפניות יוצאות בוואטסאפ ובאימייל, בלי צורך בחיבור API לכל ספק.

קהל היעד העיקרי הוא סוכנויות נסיעות מקוונות, סוכני נסיעות ומפעילי טיולים שרוצים להציע ליווי נוסעים בלייבל לבן. העסק מעביר את נתוני הטיול דרך API. הנוסע או נציג הסוכנות מאשרים כל פנייה לפני שליחתה; שינוי בהזמנה תלוי באישור הספק, ונציג יכול להמשיך את הטיפול בפניות שלא נפתרו. דברו איתנו על פיילוט לסוכנות.

הבעיה

הזמנות נפרדות. שינוי אחד שמשפיע על כמה מהן.

הנוסע מזמין טיסה באתר אחד, מלון באתר שני, הסעה בשלישי ופעילות ישירות מול המפעיל. כשהטיסה מתעכבת, ייתכן שצריך לעדכן כמה ספקים, לבדוק את תנאי כל הזמנה ולעקוב אחר התשובות.

שינוי הטיסה הוא רק חלק מהעבודה. הנוסע או צוות הסוכנות עדיין צריכים להבין אילו הזמנות נוספות מושפעות ומה כבר סוכם עם כל ספק. Kiipling מרכז את ההקשר הזה ואת הפניות שנובעות ממנו.

Kiipling מכין פניות בוואטסאפ ובאימייל ומרכז את התשובות באותו אירוע. העסק מעביר נתוני טיול דרך API, אך אין צורך בחיבור API נפרד למלון, לחברת ההסעה או למפעיל הפעילות כדי לפנות אליהם.
